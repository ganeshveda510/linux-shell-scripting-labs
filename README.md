## Project: Automated Backup Script

The `backup.sh` script automates the process of backing up files from a target directory to a destination directory.

### Features

* Accepts source and destination directories as command-line arguments
* Performs file and directory backup operations
* Uses Linux shell commands
* Includes validation and error handling
* Designed for repeatable backup operations
