# Linux Shell Scripting Labs

Hands-on Linux and Bash shell scripting project focused on command-line operations, file management, and basic infrastructure automation.

## Project: Automated Backup Script

`backup.sh` is a Bash script that automates the backup of files and directories from a specified source directory to a destination directory.

### What I Implemented

* Accepted source and destination directories as command-line arguments
* Used Bash variables and command-line parameters
* Performed file and directory operations
* Implemented directory validation
* Used Linux command-line utilities
* Added validation and error handling
* Tested the backup process in a Linux environment

### Example Usage

```bash
./backup.sh /path/to/source /path/to/destination
```
